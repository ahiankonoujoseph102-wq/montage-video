# Logos des outils

Fichiers SVG de [Simple Icons](https://simpleicons.org) (paquet npm `simple-icons` 16.36.0, licence CC0 1.0), sauf
`chatgpt.svg` (Wikimedia Commons, ajouté par le lancement « Captures des outils »). Les logos sont des marques de leurs
propriétaires : ils sont montrés seulement pour identifier l'outil dont la vidéo parle, jamais pour suggérer un
partenariat (voir `DISCLAIMER.md` de Simple Icons). Couleurs officielles dans `logos.json`.
