# Captures des outils cités dans les vidéos

Captures d'écran des pages publiques, prises sans compte par `scripts/captures_outils.py` (lancement GitHub
« Captures des outils »). Usage : montrer à quoi ressemble l'outil quand la vidéo le cite (citation, identification) ;
le nom est écrit en texte, aucun partenariat ni affiliation n'est suggéré. Une capture n'est utilisée que si
`projets/outils/<outil>.png` existe (vérifiée).
