# Voix off des démonstrations (version 2) — à enregistrer par Joseph

Lisez chaque phrase calmement, avec une petite pause entre deux phrases. Un seul fichier suffit, dans l'ordre.
Pas besoin de numéros : je les retrouve. Durée totale ≈ 3 min.

## Créer son compte Claude
Ouvrez votre navigateur, Chrome par exemple. Dans la barre de recherche, tapez claude point a i.
Touchez « Continuer avec Google ». Choisissez votre adresse Gmail. Et voilà : votre compte Claude est créé, c'est gratuit.

## Créer son compte GitHub et un dépôt privé
Dans Google, tapez GitHub, puis ouvrez github point com. Touchez « S'inscrire ».
Touchez « Continuer avec Google » et choisissez votre adresse. Votre compte GitHub est prêt.
Pour créer un dépôt, touchez le petit « plus » en haut, puis « Nouveau dépôt ».
Donnez un nom à votre dépôt, sans espace. Ajoutez une courte description.
Maintenant, le plus important : choisissez « Privé ». Vous voyez le cadenas ? Personne d'autre ne verra votre code.
Touchez « Créer le dépôt ». C'est fait : votre coffre-fort est prêt.

## Relier Claude Code à GitHub
Ouvrez Claude Code dans votre navigateur, avec votre compte Claude. Je vous conseille la version web : c'est plus simple que l'application.
Touchez « Nouvelle session ». Claude Code vous demande de relier votre compte GitHub : touchez « Connecter ».
Autorisez l'accès, puis revenez dans Claude Code.
Créez maintenant un environnement : donnez-lui un nom, choisissez l'accès à Internet, et validez.
Votre développeur est prêt à travailler.

## Écrire son projet dans le bloc-notes
J'ouvre Google Keep, mon bloc-notes. Je touche le « plus » pour créer une nouvelle note.
Je touche le micro et je dicte mon projet, comme si je parlais à un ami. Les fautes n'ont aucune importance.
Je relis rapidement, et j'ajoute ce qui manque : mon nom, mon activité, mon objectif.

## Donner le message au chef de projet
J'ouvre Claude et je démarre une nouvelle conversation.
Je colle le message du guide, « Tu es mon chef de projet », puis je colle ma description en dessous.
Je touche « Envoyer ». Claude me répond et me pose ses questions, une par une.

## Le nom de domaine
Pour le nom de domaine, je vais sur Cloudflare. Je tape le nom que je veux, ici kekeli.
Cloudflare me dit s'il est libre et combien il coûte par an. Je choisis celui que le chef de projet m'a conseillé.

## Créer le dépôt du projet
Sur GitHub, je crée le dépôt de mon projet : je l'appelle kekeli, j'ajoute une description, je choisis « Privé », et je crée le dépôt.

## Envoyer la première consigne à Claude Code
J'ouvre Claude Code. Je choisis mon dépôt kekeli et mon environnement.
Je colle la consigne préparée par le chef de projet, puis je touche « Envoyer ».
Claude Code ne construit rien tout de suite : il me présente d'abord son plan.
Je copie ce plan et je le donne à mon chef de projet. Il le vérifie et me dit quoi corriger.
Quand le plan est bon, je réponds à Claude Code : « Validé, lance. »
